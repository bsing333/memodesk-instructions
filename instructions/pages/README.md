# Pages Folder

This folder contains the PNG instruction pages for the interactive booklet.

## Required Files
- `page-1.png` - Cover page
- `page-2.png` - Table of contents
- `page-3.png` - Introduction
- `page-4.png` - Getting started
- ... (continue through page-X.png)

## File Naming
All files must follow the pattern: `page-X.png` where X is the page number (1, 2, 3, etc.)

## Design Notes
- Design these pages in Figma
- Export as PNG format
- Recommended dimensions: 800x600 or similar aspect ratio
- Each page should contain the instruction content for that section

## Current Status
- Placeholder files will be replaced with actual PNG designs
- The interactive booklet will automatically detect how many pages are available
- No need to hardcode page counts - the system discovers them dynamically

## Usage
The booklet will automatically scan this folder and work with however many pages you upload.
